One rule applied to both screens. On N1 a player who has cashed out is done for the night; on E2 a player whose stack has been counted is done being counted. In both cases the right-hand column changes meaning — from money in to a signed result before deductions — so the row has to say which it is showing. Three ways to say it, each drawn on both screens.
