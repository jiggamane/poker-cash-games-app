Type check · board versus build

The board and the app are not setting the same type

Every board file declares -apple-system, 'SF Pro Text', 'Figtree' and no board ever names a typeface outright. That stack resolves to SF Pro on a Mac and to something else wherever SF Pro is absent, so the boards and the build are not guaranteed to be setting the same face — and the screenshots say they are not. Two faces never differ by one uniform amount either: the difference runs per role, which is why a row drawn with no slack breaks even when the sizes are right. What to put in the handoff
1Name one typeface and stop shipping a stack. A stack means the reviewer and the device can resolve different faces, so no width on any board is a fact. If the answer is Figtree, every board gets redrawn in Figtree so approvals happen against real widths; if it is SF Pro, the build stops loading Figtree.
2Specs get drawn at 393pt, not 402. The narrowest supported width is the one the layout is proven at.
3No text in this app may break inside a word. Titles and figures never wrap or shrink; meta truncates; a name that still does not fit gets an ellipsis, never a second line it was not designed for.
4Every row height in the spec is a maximum. If the list cannot show the number the summary claims, the summary is wrong: it says what is visible, or the list scrolls.
