Behaviourwhat CC needs beyond the pixels
Decided Admin writes, everyone reads Only the admin can add a spend or change a rule. Everyone else opens the same screens with the list and the preview intact, the buttons gone and the header meta reading "admin only". No hidden totals — the bill is public, editing it is not. A spend can land after the count Somebody always remembers the pizza after the night ends. Adding one during settle-up is allowed and recalculates every winner's share and every transfer. The settlement screen must state that it changed rather than silently redrawing. Covered by, four cases One player. Several players, whose fronted amounts must sum to the spend — the row turns red and Save is blocked until it does. The kitty, which pays it directly and takes no reimbursement. Or nobody yet, which leaves it unpaid and shows an amber "unpaid" tag in the list until someone is named. The note is optional The tags above the field — Food, Drinks, Venue — write those words into the note; tapping one is the fast path, typing over it is fine, and leaving the note empty is fine too. An empty note shows as the amount alone in the list. There is no category on a spend, so nothing here touches the arithmetic.
